# Early run retained for audit

The three model fixes were host-verified, and the model-free recheck reproduced
their passing checks. All three GitHits requests returned HTTP 401. No matched
comparison was obtained.

An evidence-capture issue was found before the final report: `prompt.txt` was
written through Windows text-mode newline conversion, while model stdin was
sent as UTF-8 bytes. Those saved text files therefore are not byte-exact stdin
captures. Original requests, model JSON events, patches, host evaluations and
Git bundles are retained unchanged, with their original manifest.

The adapter now writes the exact stdin bytes. Run 002 is the final run for the
report. Do not pool the early run into its denominator or describe the early
prompt files as byte-exact captures. The fixtures, model, budgets and checks
were not changed in response to these outcomes.
